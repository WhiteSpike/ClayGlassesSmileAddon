# Clay Glasses Smile Addon

A Lethal Company addon which patches the behaviour of Wesley's enemy "Smile"(from [Wesley's Enemy Variants](https://thunderstore.io/c/lethal-company/p/Magic\_Wesley/Wesleys\_Ememy\_Variants/)) for the vanish range be affected by the Clay Glasses upgrade (from [Lategame Upgrades](https://thunderstore.io/c/lethal-company/p/malco/Lategame\_Upgrades/))
